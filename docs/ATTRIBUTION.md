# Attribution and source register

Weather data, when captured live, is supplied by [Open-Meteo](https://open-meteo.com/) using the expressly selected ERA5 model, based on ECMWF/Copernicus reanalysis. [Historical API documentation](https://open-meteo.com/en/docs/historical-weather-api) defines the request model and parameters. [ECMWF's ERA5 documentation](https://confluence.ecmwf.int/pages/viewpage.action?pageId=414588701) explains preliminary ERA5T and later consolidated data; the event freezes the served response within its fourteen-day deadline.

The [Open-Meteo terms](https://open-meteo.com/en/terms) distinguish API access conditions and data licensing. This educational, non-commercial testnet prototype does not assume permission for commercial or promotional use. Obtain suitable provider authorization/subscription before such use, preserve attribution, and examine underlying dataset conditions. Synthetic fixtures are generated by this project and labeled throughout; they must never be attributed as provider observations.

Original application source is MIT licensed. Dependency licenses remain with their packages: OpenZeppelin, Foundry/forge-std, Next.js, React, wagmi, viem, TanStack Query, Tailwind, Radix, lucide, and esbuild. Local MONSKILLS routing and relevant guidance were read before implementation. Native Windows Foundry 1.8.0 is workspace-local; source compilation uses Solidity 0.8.28 and OpenZeppelin 5.6.1.
