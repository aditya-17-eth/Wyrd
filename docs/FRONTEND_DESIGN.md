# Aegis frontend identity

The platform is a category-neutral marketplace for transferring risk. Only Pune weather contracts are implemented. Unsupported categories are navigable previews, with no quotes, financial figures, or activity.

Palette: obsidian #0A0B0F, navy #12141A, elevated #1A1D25, off-white #F5F5F2, secondary #9297A5, Monad violet #836EF9. Shared financial components use violet with muted semantic green/red/amber. Thermal color is restricted to illustrative weather art.

Typography: locally bundled Instrument Sans for the interface and editorial display; IBM Plex Mono for monetary values and hashes. Left-aligned headings and short explanatory lines. Common spacing, surfaces, and navigation persist across category changes.

Composition: a wide headline beside a conceptual risk/capital/settlement diagram. Discovery follows with a horizontal category strip, filter controls, and compact market cards. The reference images inform bold composition (SPRINT), discovery hierarchy (Polymarket), capital transparency (Morpho), and editorial breathing room (Ethereum Foundation). No reference brand assets are reproduced.

Category registry: weather uses thermal contours; travel uses aviation routes; agriculture uses field/vegetation patterns; logistics uses maritime routes and containers; events uses a venue plan. Every diagram is illustrative, not measured data. The category art component supports both banners and thumbnails. Future observed data must be explicitly sourced and dated. No fabricated financial charts.

Contract reads, wallet simulation, tight gas estimation, receipt/finality handling, evidence verification, immutable event terms, and capital locks remain the source of behavior. Live and synthetic events are separated in discovery. Financial integers are formatted and ratios computed with bigint.
# October 10 theme revision

The latest user direction supersedes the original dark global palette. Inspiration: [Mehmet Özsoy / Orizon landing page](https://dribbble.com/shots/27569663-Landingpage-Design). Aegis uses warm paper `#F7F6F2`, near-white panels `#FDFCF9`, black ink `#171713`, amber `#FFBA41`, orange `#F57411`, scarlet `#DB1405`, and oxblood `#8D1A0F`. These are discrete printed bands, not global thermal weather gradients. Monad purple remains a restrained network identifier.

Georgia carries editorial headings, Instrument Sans carries navigation and transaction interfaces, and Plex Mono carries exact financial values and hashes. The homepage features an original isometric vault illustration linking defined events, reserved capital and verified evidence. Dashed illustration frames, black controls, quiet neutral borders and generous spacing carry across market discovery, purchases, underwriting, portfolio and resolution. Category-specific visuals and all verified financial/data behavior remain intact.
